# Thornwake — vegetation concept sheets (prompt for Noor)

Noor, please create **concept sheets only — do not make 3D models.** Each sheet shows one plant on a plain,
solid-coloured background. Tom will hand the sheets to Codex, which will build stylized 3D models of them in Blender,
so every sheet must explain the plant's shape clearly from several sides.

Work through the list in order: **Giant Trees biome first**, then the other biomes, then the shared grass and flower
sets. Deliver in batches (see "Delivery" at the end).

---

## 1. Style rules (every sheet)

- **Stylized shapes:** simple, chunky, readable forms — tapered trunks, clumped foliage masses, a few big branches.
  No photoreal twig clutter. Exaggerate what makes the species recognisable; it must read at a glance from 50 m.
- **Pixel-art textures** painted on those shapes: visible pixel clusters, 2–4 shades per colour, crisp edges, no
  gradients, no blur.
- **Palette:** slightly muted, natural colours (the game raises saturation itself). No neon greens, no pure white.
- **Lighting:** flat, soft front light so the true colours are visible. No strong shadows, no rim light.
- **Background:** one flat solid colour. Mid grey `#7F7F7F` by default; magenta `#FF00FF` for grey or silver plants.
  No ground plane, no scenery, no cast shadows, no transparency.
- **Views on each sheet:** front, side and three-quarter view, drawn to the same scale and roughly orthographic (no
  strong perspective), plus a top view for trees and wide plants, plus close-up swatches of the bark and leaf texture.
  These views are what Codex uses to model in Blender, so keep proportions identical between views.
- **Variants:** where listed, draw 2–3 variants side by side on the same sheet.
- **Labels:** species name and real height in metres, written outside the plant (a small human figure for scale is
  welcome). Short labels on parts that matter ("trunk flare", "leaf clump") are fine.
- **Never:** 3D renders or turntables, scenery, cropping the plant.

## 6. Delivery

- One PNG per sheet, at least 2048 px on the long side, solid background (no transparency).
- File name: `biome_plant_variant.png`, lower case, e.g. `giant-trees_sequoia_ancient.png`, `shared_poppy_patch.png`.
- Every sheet: front, side, three-quarter (plus top for trees), texture swatches, height in metres.
- Batch 1: the Giant Trees biome. Then one batch per biome group, then the shared grass and flower sets.
- One zip per batch, with a short text file listing the sheets inside.
